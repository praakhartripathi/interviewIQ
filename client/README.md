# InterviewIQ Client

React frontend for InterviewIQ.

## Features
- SaaS landing page
- Auth pages (signup/login + Google sign-in)
- Protected dashboard
- Resume upload and AI analyze flow
- Interview practice UI

## Scripts
```bash
npm start
npm run build
npm test -- --watchAll=false
```

## Env
Create `.env` in `client/`:
```bash
REACT_APP_API_URL=http://localhost:8080
REACT_APP_GOOGLE_CLIENT_ID=your_google_web_client_id
```
